Voice Input Local API

Интерактивная документация для тестирования REST API расшифровки аудио. Версия 1.0

GET /capabilities Список доступных моделей и функций ›

Возвращает список установленных моделей транскрипции, их статус и поддерживаемые функции API. Параметров не требует.

POST /transcribe Отправить файл на расшифровку ›

Загружает аудио/видео файл и ставит его в очередь на расшифровку. Возвращает task_id для отслеживания результата через GET /result/{task_id}.

Параметры запроса
Форматы: wav, mp3, m4a, mp4, webm, ogg, flac, aac, wma, mov, mkv
Выберите модель или оставьте по умолчанию. Модель должна быть скачана в приложении.
Ожидание результата...
GET /result/{task_id} Получить результат расшифровки ›

Возвращает статус и результат задачи по её идентификатору. Статусы: queued → processing → done / error. Результат хранится 1 час.

Параметры
Скопируйте task_id из ответа POST /transcribe или нажмите «Вставить последний»
